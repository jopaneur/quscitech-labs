# QAIS Labs — Master Index

This repository contains beginner (Part 1) and advanced (Part 2) quantum AI system labs.  
Each lab is provided in two editions:
- **Code-Enabled** → runnable in Google Colab or locally with Qiskit installed.  
- **No-Code** → read-only with coding guidance, designed for conceptual study or assignments.  

---

## 📘 Quick Access to Lab Sets

- [**Part 1 — Code-Enabled Labs**](Beginner_Labs/notebooks/README.md)  
  11 beginner labs with runnable circuits and analyses.

- [**Part 1 — No-Code Labs**](Beginner_Labs/notebooks_no_code/README.md)  
  11 beginner labs in read-only mode with coding guidance.

- [**Part 2 — Code-Enabled Labs**](Advanced_Labs/notebooks/README.md)  
  7 advanced labs demonstrating encoding metrics, hybrid pipelines, Grover success vs noise, and QALIS stress tests.

- [**Part 2 — No-Code Labs**](Advanced_Labs/notebooks_no_code/README.md)  
  7 advanced labs in read-only mode with step-by-step coding guidance.

---

### 🔑 Using the Labs

- Open any lab notebook via the **Colab badge** in the local README file.  
- For code-enabled labs: run the **Environment Setup** cell first.  
- For no-code labs: follow the **Coding Guide** to reimplement circuits yourself.  

---

### 💾 Saving or Submitting Your Work

- **Students:**  
  1. Export your key plots or the entire notebook to PDF (`File → Print/Save as PDF`).  
  2. Save the notebook (`.ipynb`).  
  3. Upload both PDF and notebook to your LMS or repository as instructed.  
  4. Include your name and lab number in submissions.  

- **Professionals / Self-Learners:**  
  1. Save the notebook (`File → Download .ipynb`) to your computer for personal reference.  
  2. Optionally export as PDF for archiving.  
  3. Use GitHub/GitLab if you want to version-control your work.
