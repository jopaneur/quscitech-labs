# Image Assets — E1_3_Angle_Encoding_Statevectors_NoCode

This directory stores **illustrations, diagrams, and figures** used in this lab.

## Purpose
Visuals clarify abstract quantum concepts like:
- Rotations on the Bloch sphere
- Amplitude encoding of classical data
- Statevector representation under angle mapping

## File Guidelines
- Use `.png`, `.svg`, or `.jpg` formats (optimized, ≤1 MB each).
- Source diagrams should follow QuSciTech’s **Visual Identity Standard** (blue/amber palette).
- Large vector graphics should be referenced via link, not embedded.

## CI/CD Note
All images are checksum-verified on commit.  
Images may be compressed during automated build for web deployment.
