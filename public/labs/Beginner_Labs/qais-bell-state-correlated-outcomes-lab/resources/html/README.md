# Public HTML — Bell-State (Correlated Outcomes)

- `qais-bell-state-correlated-outcomes-lab.html` — self-contained page that
  simulates Bell |Φ⁺⟩ correlated measurements in the Z basis, renders a table and
  a bar chart without external libraries, and falls back to a PNG image if JS is
  disabled (noscript) or canvas is unavailable.
