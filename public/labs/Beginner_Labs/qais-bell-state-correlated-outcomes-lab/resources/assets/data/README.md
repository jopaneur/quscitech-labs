# Data — Bell-State Lab

- `bell_demo_counts.csv` — tiny example dataset of joint outcome counts for a
  Bell |Φ⁺⟩ experiment measured in the Z basis. Used by the HTML page and the
  exporter script to build a fallback PNG.

Columns:
- `outcome` — one of `00,01,10,11`
- `count`   — non-negative integer
