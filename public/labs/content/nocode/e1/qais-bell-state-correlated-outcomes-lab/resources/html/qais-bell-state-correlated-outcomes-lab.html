Bell State — Correlated Outcomes (|Φ⁺⟩, Z-basis)

This beginner lab shows how Bell pairs measured in the same Z basis produce correlated bits. We simulate 1,000 pairs from |Φ⁺⟩ and add a small flip noise ε to mimic imperfections. Counts and the correlation coefficient are computed client-side; a static PNG fallback is available.
